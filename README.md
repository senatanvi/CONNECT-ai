# CONNECT-ai
CONNECT 🚆
AI-powered morning journey planner

CONNECT is an AI-assisted web application designed around a simple question:

"What do I need to do this morning to arrive on time?"

Instead of making users work out their journey themselves, CONNECT works backwards from an arrival time to calculate a recommended:

Arrival time → Journey → Leave time → Preparation time → Wake-up time

💡 The Problem

Planning a morning journey often means checking multiple sources for transport times, delays, traffic, weather and journey duration.

CONNECT aims to bring this information together into one simple morning briefing.

🚀 Key Features
Arrive By — choose when you need to arrive
Wake-up Time — calculates when you need to get ready
Leave Time — recommends when to leave
Journey Planning — supports different transport options and routes
Reliability Buffer — accounts for uncertainty rather than relying on one journey-time estimate
Why? — explains the reasoning behind recommendations
What Changed? — compares today's journey with a user's normal journey
Late Mode — recalculates the plan when the user is running late
Saved Journeys — supports recurring journeys such as Home → Work
Traffic & Transport Conditions — provides contextual information about the journey
Responsive Design — designed primarily for quick mobile use

🧠 Development Approach

CONNECT was developed during SEO London's first AI Buildathon.

The project involved rapidly moving from an initial problem statement to a functional prototype, using AI-assisted development to accelerate experimentation and iteration.

The product was designed around a decision-making workflow rather than presenting users with large amounts of raw information.

📊 Handling Uncertainty

A key design principle was avoiding false precision.

Rather than presenting a journey as simply:

38 minutes

CONNECT can communicate:

38 minutes
Usually 35–42 minutes

This allows uncertainty and reliability to become part of the recommendation rather than hidden from the user.
